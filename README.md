# Aplicaciones Web: ejercicios 5 y 6

Ejercicios en PHP con formularios HTML.

- [Ejercicio 5: Sueldo quincenal](ejercicio5_sueldo/): calcula el sueldo bruto por turnos (diurna, vespertina y nocturna), las retenciones de Ahorro Habitacional y Seguro Social y el sueldo neto.
- [Ejercicio 6: Factura](ejercicio6_factura/): calcula el subtotal, el IVA del 12% y un descuento del 15% si el total con IVA supera 150 $.

Cada carpeta tiene un `index.html` con el formulario, un archivo `.php` que hace los cálculos y su propio `README.md`.

Para usarlos, copia la carpeta en `C:\xampp\htdocs`, enciende Apache y abre `http://localhost/aplicaciones_web_ujgh2/`.
